# 批量图像编辑

批量编辑把**一条指令同时应用到多张图像**。无需逐张修改，aiFetchly 会在后台执行一个有界的任务：每张图像各由一次隔离的编辑处理，并在对话中只显示一张进度卡片。典型任务：

- "把 20 张产品照片全部换成白色背景。"
- "把这次生成的所有图像调亮。"
- "给这些图像每张都加上我的水印文字。"

## 什么时候会进入批量编辑

以下三种情况会触发批量：

1. **要求对超过三张图像做同一编辑。** 聊天直连请求最多携带三张图像，因此更大的集合会自动转入批量（aiFetchly 会先请您确认）。
2. **在参考托盘中选中四张或更多图像。** aiFetchly 会询问："已选择超过 3 张图片。改为按批次独立处理它们吗？"确认后开始批量，或拒绝后按每三张一批编辑。
3. **要求处理一个大的编号集合**，例如"编辑第 4 张到第 12 张"。执行前会出现同样的确认。

:::info 先确认，再产生费用

批量确认对话框总是会在开始前显示准确数量。您确认之前不会运行任何任务，也不会产生 AI 用量费用。

:::

## 执行批量编辑

1. **生成或选中**要编辑的图像（见 [AI 图像生成与编辑](./ai-image-generation)）。
2. **发送一条适用于全部图像的指令**，例如"把这些全部换成白色背景"。
3. 当出现"按批处理？"对话框时**确认批量**。对话框会列出将被编辑的图像数量。
4. 在对话中**查看进度卡片**（详情见下）。每张图像持久保存完成后，结果随即出现。
5. **处理结果**：下载或检查已完成的图像，并重试失败的部分。

## 进度卡片

一张卡片跟踪整个任务，绝不会每张图像刷一条消息刷屏：

- **汇总行**：`已完成 {completed}/{requested} · 并发数 {concurrency}`，以及任务状态（运行中、已完成、部分完成、失败、已取消）。
- **停止批次**：随时停止任务。已完成的图像仍然保留保存；尚未开始的项目会被标记为已取消。
- **可展开的失败明细**：列出每个失败项目及其文件名和简短原因。
- **重试失败项（N）**：任务结束后，只重新运行失败或被取消的项目。成功的图像绝不会被重新处理。

### 部分成功是安全的

20 张里有 18 张成功，您就保留这 18 个结果。某一张失败不会殃及其他图像。点击 **重试失败项** 即可给那两张失败图像再来一次。

## 批量的运行方式

批量编辑为规模而设计，同时不把聊天撑大：

- **一张图，一个任务。** 每张图像由一次独立的 AI 请求配合共享指令完成编辑。输入到输出的对应关系保持不变：结果按您选择图像的顺序汇报，而不是按完成顺序。
- **并发有上限。** 同一时刻最多处理 **3 张**（由协调器在 1 至 3 之间调整）。50 张图像的任务是 50 次小请求，而不是一次巨型请求。
- **主对话保持轻量。** 主会话只接收进度、汇总和完成的图像。图像字节和逐项对话记录都留在隔离的工作单元里，因此在长任务期间和结束后都能继续顺畅聊天。
- **输出持久保存。** 每张完成的图像在进度卡片引用它之前就已保存到本地，因此服务商临时链接过期不会弄丢您的成果。

:::note 每张图像仍然消耗 AI 用量

批量隔离缩小的是会话上下文，并不会让编辑免费。每张图像都是图像模型的一次操作。确认对话框会提前显示项目数量，与直接聊天相同的工具审批规则同样适用。

:::

## 限制

| 限制 | 数值 |
|---|---|
| 每个批量任务的图像数 | 1 至 50（自动去重） |
| 并行图像编辑数 | 1 至 3（默认 3） |
| 单次直接请求的图像输入 | 3 |
| 所有项目使用同一指令 | 是，每个批量共享一条指令 |
| 合成（把多张图合并为一张） | 批量不支持；请使用最多 3 张的直连方式 |

## 故障排查

**部分项目失败了。**
打开进度卡片上的失败明细查看原因，然后点击 **重试失败项（N）**。只有失败的项目会重跑。

**"该图片超过大小限制"** 或 **"不支持的图片类型"。**
存储的原件可能过大或格式不受支持（支持 PNG、JPEG、WebP）。请重新生成该图像，或先把它保存到工作区，在那里缩放或转换格式，再以工作区文件批量方式执行编辑。

**"原图已不存在"。**
某个引用背后的存储文件丢失了。请重新生成该图像并为它新建一个批量任务。

**"Image editing is unavailable: no edit-capable model is configured"。**
您的 [AI 服务商](../settings/ai-provider)没有提供图像编辑模型。请先配置，再重试失败的项目。

**不小心停止了批量任务。**
已完成的结果早已保存。任务结束后点击 **重试失败项**：它也会带上被取消（从未开始）的项目。

**批量看起来卡住了。**
并发上限是三个并行编辑，大任务需要一些时间。请查看汇总行：如果已完成数量长时间不再增长，使用 **停止批次**，然后重试剩余项目。
