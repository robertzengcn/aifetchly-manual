# 子智能体

子智能体是可复用的专业 AI 智能体定义。它们描述一个聚焦角色、系统提示词、允许使用的工具、模型偏好和运行限制，供 aiFetchly 用于特定 AI 工作。

插件可以和 AI Skills、MCP 服务器一起安装子智能体，你也可以为自己的重复工作流创建手动子智能体。

## 打开子智能体

1. 在左侧导航中点击 **设置**。
2. 打开 **系统设置**。
3. 点击 **管理子智能体**。

子智能体页面包含紧凑表格、搜索和筛选控件、详情对话框，以及 **添加子智能体** 操作。

## 子智能体来源

| 来源 | 说明 |
|---|---|
| **内置** | aiFetchly 自带的智能体。它们是只读的。 |
| **插件** | 由插件安装的智能体。它们在子智能体页面中只读，但可以启用或禁用。 |
| **工作区** | 从工作区文件加载的智能体。要修改它们，请编辑对应的工作区智能体文件。 |
| **手动** | 你在 aiFetchly 中创建的智能体。可以编辑、启用、禁用或删除。 |

使用来源筛选器可以显示全部子智能体，或只显示某一种来源。

## 查找和筛选子智能体

子智能体表格包含：

| 列 | 说明 |
|---|---|
| **Agent** | 显示名称和运行时 ID。 |
| **Description** | 智能体作用的简短摘要。 |
| **Source** | 内置、插件、工作区或手动。 |
| **Mode** | 智能体角色，例如 `specialist`、`verifier`、`coordinator` 或 `formatter`。 |
| **Tools** | 该智能体允许使用的工具数量。 |
| **Status** | 启用或禁用；异常智能体会显示警告标识。 |
| **Actions** | 可用时显示启用或禁用开关。 |

你可以按智能体 ID、名称、描述或插件名称搜索。状态筛选器可显示全部、已启用或已禁用的智能体。

## 查看详情

点击子智能体行可打开详情面板。面板显示：

- 智能体名称和运行时 ID
- 来源和插件所有者（如适用）
- 状态和健康情况
- 描述
- 源文件或插件组件路径
- 模式和默认模型
- 最大工具调用次数
- 最大运行时间
- 最大继续调用次数
- 允许使用的工具
- 系统提示词

只读智能体会显示提示，说明应在哪里编辑。手动智能体会显示 **编辑子智能体** 和 **删除此子智能体** 操作。

## 创建手动子智能体

1. 点击 **添加子智能体**。
2. 输入 **名称**。
3. 检查或编辑生成的 **ID slug**。
4. 添加 **描述**。
5. 选择 **模式**。
6. 编写 **系统提示词**。
7. 添加用逗号分隔的 **允许工具**。
8. 可选设置 **默认模型**。
9. 设置运行限制。
10. 可选添加 **输出 Schema** JSON 对象。
11. 选择该子智能体是否以 **启用** 状态开始。
12. 点击 **保存**。

ID slug 创建后会锁定，因此请选择稳定的标识符。

## 手动子智能体字段

| 字段 | 说明 |
|---|---|
| **名称** | 表格和详情面板中显示的可读名称。 |
| **ID slug** | 稳定的运行时标识符。首次保存前会从名称自动生成，之后不能更改。 |
| **描述** | 简短说明何时使用该子智能体。 |
| **模式** | 功能角色：`coordinator`、`specialist`、`verifier` 或 `formatter`。 |
| **系统提示词** | 子智能体的指令。应保持自包含且具体。 |
| **允许工具** | 用逗号分隔的工具名称。运行时策略仍然适用。 |
| **默认模型** | 该子智能体的可选模型偏好。 |
| **最大工具调用次数** | 单次运行期间允许的最大工具调用次数。 |
| **最大运行时间（秒）** | 单次子智能体运行的最长时间。 |
| **最大继续调用次数** | 最大继续轮次数。 |
| **输出 Schema** | 可选 JSON 对象，用于描述期望的结构化输出。 |
| **启用** | 控制该子智能体是否可被运行时使用。 |

## 编辑和删除手动子智能体

打开手动子智能体并点击 **编辑子智能体**，即可更新名称、描述、系统提示词、允许工具、模型、运行限制、输出 Schema 或启用状态。

要移除手动子智能体，打开详情面板并点击 **删除此子智能体**。删除是永久操作。

## 插件安装的子智能体

插件可以在 `agents/` 目录下包含 Markdown 文件，或通过插件 manifest 声明子智能体。安装后，这些文件会成为 aiFetchly 中由插件拥有的子智能体定义。

插件子智能体可以包含：

- `name`
- `description`
- `tools`
- `model`
- `mode`
- 运行限制
- 作为系统提示词的 Markdown 指令

插件拥有的子智能体会按插件命名空间命名，例如 `lead-pack:researcher`。嵌套文件夹可以创建更深层 ID，例如 `lead-pack:review:verifier`。

## 管理插件子智能体

插件子智能体会出现在两个位置：

- **系统设置 → 子智能体**：完整目录。
- **Plugin Manager → 插件详情 → Subagents**：某个插件拥有的智能体。

在插件详情的 Subagents 标签中，你可以查看每个智能体的名称、ID、模式、工具数量、健康状态和启用状态。禁用一个插件子智能体不会禁用该插件的其他 skills、MCP 服务器或子智能体。

如果整个插件被禁用，即使某个子智能体的单独开关处于开启状态，它也不可用。重新启用插件会恢复之前保存的组件级设置。

## 健康状态和警告

子智能体可以报告 `healthy`、`disabled`、`partial_load`、`invalid` 或 `missing_files` 等健康状态。

警告通常表示 aiFetchly 以受限方式加载了智能体，或在源定义中发现了问题。打开详情面板或插件诊断查看原因。

## 安全注意事项

- 插件子智能体是定义，不是独立程序。
- 插件提供的安全敏感字段，例如权限模式、hooks、直接注册 MCP 服务器或特权执行设置，会被忽略或产生警告。
- 允许工具定义了子智能体的上限。aiFetchly 仍会将该列表与已启用工具和运行时策略相交。
- 手动系统提示词应保持自包含，因为子智能体不应假设自己可以看到完整的父级聊天历史。
