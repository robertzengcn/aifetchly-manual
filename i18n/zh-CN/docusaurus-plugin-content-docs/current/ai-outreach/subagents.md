# 子智能体

子智能体是可复用的专业 AI 智能体定义。它们描述一个聚焦角色、系统提示词、允许使用的工具、模型偏好和运行限制，供 aiFetchly 用于特定 AI 工作。

插件可以和 AI Skills、MCP 服务器一起安装子智能体，您也可以为自己的重复工作流创建手动子智能体。

## AI 如何使用子智能体

您不会直接调用子智能体。在每次聊天开始时，aiFetchly 会向 AI 的上下文中注入一个 **Available AiFetchly agents** 列表 —— 每个条目显示该智能体的运行时 ID、描述和来源。当某个任务合适时，AI 会使用该 ID 调用 **`run_subagent`** 工具。随后子智能体使用自己的系统提示词、允许的工具和运行限制运行，并将结果返回给主 AI。

## 内置智能体

aiFetchly 自带一个内置子智能体：

- **Lead Researcher**（`agent-lead-researcher`）—— 一个 `specialist`，使用 search-scraper 和 Knowledge Library 工具为某个潜在客户收集公开的商业背景（行业、摘要、产品、信号），并返回一个结构化的 JSON 对象，其中包含来源 URL 和置信度评分。它是只读的。

## 打开子智能体

1. 在左侧导航菜单中点击 **系统设置**。
2. 点击 **管理子智能体**。

子智能体页面包含一个紧凑表格、搜索和筛选控件、详情对话框，以及 **添加子智能体** 操作。

## 子智能体来源

| Source | Description |
|---|---|
| **内置** | aiFetchly 自带的智能体。它们是只读的。 |
| **插件** | 由插件安装的智能体。它们在子智能体页面中只读，但可以启用或禁用。 |
| **工作区** | 从工作区的 `.aifetchly/agents/` 文件加载的智能体。您可以在此处启用或禁用它们；要修改其定义，请编辑对应的工作区文件。工作区智能体只有在工作区被信任后才会加载。 |
| **手动** | 由您在 aiFetchly 中创建的智能体，**或**以 Markdown 文件形式定义在 `~/.aifetchly/agents/` 下。它们可以编辑、启用、禁用或删除。 |

使用来源筛选器可以显示全部子智能体，或只显示某一种来源。

## 查找和筛选子智能体

子智能体表格包含：

| Column | Description |
|---|---|
| **Agent** | 显示名称和运行时 ID。 |
| **Description** | 智能体作用的简短摘要。 |
| **Source** | 内置、插件、工作区或手动。 |
| **Plugin** | 拥有该智能体的插件（如适用）。 |
| **Mode** | 智能体角色，例如 `specialist`、`verifier`、`coordinator` 或 `formatter`。 |
| **Tools** | 该智能体允许使用的工具数量。 |
| **Model** | 该智能体的默认模型（若已设置）。 |
| **Status** | 启用或禁用；异常的智能体会显示警告标识。 |
| **Actions** | 可用时显示启用或禁用开关。 |

您可以按智能体 ID、名称、描述或插件名称进行搜索。状态筛选器可显示 **全部**、**已启用**、**已禁用** 或 **有警告** 的智能体。

## 查看详情

点击子智能体所在行可打开其详情面板。该面板显示：

- 智能体名称和运行时 ID
- 来源和插件所有者（如适用）
- 状态和健康情况
- 描述
- 源文件或插件组件路径
- 模式和默认模型
- 最大工具调用次数
- 最大运行时间
- 最大继续调用次数
- 允许使用的工具
- 系统提示词

只读智能体会显示一条说明，指出应在何处编辑它们。手动智能体会显示 **编辑子智能体** 和 **删除此子智能体** 操作。

## 创建手动子智能体

1. 点击 **添加子智能体**。
2. 输入 **名称**。
3. 检查或编辑生成的 **ID slug**。
4. 添加 **描述**。
5. 选择 **模式**。
6. 编写 **系统提示词**。
7. 添加用逗号分隔的 **允许工具**。
8. 可选设置 **默认模型**。
9. 设置运行限制。
10. 可选添加 **输出 Schema** JSON 对象。
11. 选择该子智能体是否以 **启用** 状态开始。
12. 点击 **保存**。

ID slug 创建后会锁定，因此请选择稳定的标识符。

## 手动子智能体字段

| 字段 | 说明 |
|---|---|
| **名称** | 表格和详情面板中显示的可读名称。 |
| **ID slug** | 稳定的运行时标识符。首次保存前会从名称自动生成，之后不能更改。 |
| **描述** | 简要说明何时使用该子智能体。 |
| **模式** | 功能角色：`coordinator`、`specialist`、`verifier` 或 `formatter`。 |
| **系统提示词** | 子智能体的指令。应保持自包含且具体。 |
| **允许工具** | 用逗号分隔的工具名称，表示子智能体允许使用的工具。运行时策略仍然适用。 |
| **默认模型** | 该子智能体的可选模型偏好。 |
| **最大工具调用次数** | 单次运行期间允许的最大工具调用次数。 |
| **最大运行时间（秒）** | 单次子智能体运行的最长时间。 |
| **最大继续调用次数** | 最大继续轮次数。 |
| **输出 Schema** | 可选 JSON 对象，用于描述期望的结构化输出。 |
| **启用** | 控制该子智能体是否可被运行时使用。 |

## 编辑和删除手动子智能体

打开某个手动子智能体并点击 **编辑子智能体**，即可更新其名称、描述、系统提示词、允许工具、模型、运行限制、输出 Schema 或启用状态。

要移除某个手动子智能体，请打开其详情面板并点击 **删除此子智能体**。删除是永久操作。

## 插件安装的子智能体

插件可以在 `agents/` 目录下以 Markdown 文件形式包含子智能体，或通过插件 manifest 声明子智能体。安装后，这些文件会成为 aiFetchly 中由插件拥有的子智能体定义。

插件子智能体可以包含：

- `name`
- `description`
- `tools`（和/或 `skills`，后者会被合并到允许工具中）
- `model`
- `mode`
- 运行限制（`maxToolCalls`、`maxRuntimeMs`、`maxTurns`）
- 可选的 `outputSchema`
- 作为系统提示词的 Markdown 指令

插件拥有的子智能体会按插件进行命名空间划分，例如 `lead-pack:researcher`。嵌套文件夹可以创建更深层级的 ID，例如 `lead-pack:review:verifier`。

## 管理插件子智能体

插件子智能体会出现在两个位置：

- **系统设置 → 子智能体**：完整目录。
- **Plugin Manager → 插件详情 → Subagents**：某个插件拥有的智能体。

在插件详情的 Subagents 标签中，您可以查看每个智能体的名称、ID、模式、工具数量、健康状态和启用状态。禁用某个插件子智能体并不会禁用该插件的其他 skills、MCP 服务器或子智能体。

如果整个插件被禁用，即使其单个启用开关处于开启状态，它的子智能体也不可用。重新启用插件会恢复之前保存的组件级设置。

## 健康状态和警告

子智能体可以报告 `healthy`、`disabled`、`partial_load`、`invalid` 或 `missing_files` 等健康状态。

警告通常意味着 aiFetchly 以受限方式加载了该智能体，或在源定义中发现了问题。打开详情面板或插件诊断可查看原因。

## 安全注意事项

- 插件子智能体是定义，不是独立程序。
- 插件提供的安全敏感字段（例如权限模式、hooks、直接注册 MCP 服务器或特权执行设置）会被忽略或产生警告。
- 允许工具定义了子智能体的上限。aiFetchly 仍会将该列表与已启用工具和运行时策略求交集。
- 请保持手动系统提示词自包含，因为子智能体不应假设自己能看到完整的父级聊天历史。
