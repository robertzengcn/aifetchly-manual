# AI 技能

AI 技能是模块化扩展，为 AI 提供在聊天过程中可调用的工具——例如网页抓取、自动化、文件访问或 shell 命令等专业能力。当某个技能被启用后，AI 可以自行决定是否使用它来回应您的请求。

## 什么是技能？

技能是一个打包的工具，具有：

- 唯一的**名称**和**版本号**。
- **来源**：**内置**（随 aiFetchly 一起发布）或**用户安装**（由您导入，或随插件一起打包）。
- **权限类别**——由技能声明的权限派生（参见[权限类别](#技能类别)）。
- **启用/禁用**状态。

## 访问 AI 技能

1. 点击左侧导航菜单中的**系统设置**。
2. 点击**管理技能**（或**AI 技能**）。

该页面以表格形式列出所有已安装的技能。

## 技能表格

| 列名 | 说明 |
|--------|-------------|
| **名称** | 技能标识符。如果该技能来自某个插件，其旁边会显示一个_"via plugin: \{name\}"_标签。 |
| **来源** | **内置**或**用户安装**徽章。 |
| **类别** | 技能的权限类别（`pure`、`network`、`filesystem`、`automation`或`shell`）。 |
| **版本** | 技能版本号。 |
| **状态** | **已启用**或**已禁用**。 |
| **操作** | 启用/禁用切换按钮和卸载按钮——**仅对用户安装的技能显示**。 |

:::note 内置技能始终开启

内置技能**既不**显示启用/禁用切换按钮，**也不**显示卸载按钮。它们无法在此页面被禁用或移除。

:::

## 导入技能

技能以`.zip`包的形式导入。

1. 点击**导入**（右上角，上传图标）。
2. 选择一个技能`.zip`文件。
3. aiFetchly 会校验该包（清单、权限、入口文件）并完成安装。

:::tip 导入提示

- 导入按钮仅支持`.zip`文件。
- 包内必须包含有效的`manifest.json`（参见[技能包格式](#技能包格式)）。
- 随插件打包的技能无需导入——当其所属插件安装时会自动出现。

:::

技能也可以通过以下途径自动出现：

- **插件**——一个插件会打包一个或多个技能；它们会以_"via plugin"_标签的形式出现在此处。可通过**[插件管理器](./plugin-manager)**来安装或移除它们。
- **本地技能目录**（进阶）——放置在`~/.aifetchly/skills/<name>/`下的技能会被自动发现。

## 启用、禁用和卸载

对于**用户安装**的技能：

- **启用 / 禁用**——使用操作列中的对勾（启用）/叉号（禁用）切换按钮。
- **卸载**——点击垃圾桶图标并确认。卸载是永久性的；要再次使用该技能，需重新导入对应的`.zip`。

内置技能没有操作控件——它们始终处于启用状态。

## 技能在聊天中的工作方式

一旦某个技能被启用，AI 会在相关时自行选择调用它。您无需按名称调用技能（不过也可以显式请求，例如*"用网页抓取器处理这个 URL"*）。

### 技能类别

每个技能都属于一个**权限类别**，该类别决定了 AI 调用该技能时如何被审批。类别取自技能清单中声明的第一个`permission`，如未声明则为`pure`：

| 类别 | 技能可以做什么 |
|--------|----------------------|
| `pure` | 通用工具——文本处理、计算、格式化。无特殊访问权限。 |
| `network` | 出站网络/HTTP 访问（抓取网页、调用 API）。 |
| `filesystem` | 本地文件读写。 |
| `automation` | 浏览器自动化、抓取、社交发布以及类似的脚本化操作。 |
| `shell` | 运行系统 shell 命令。（仅限内置`shell_execute`——永不可导入。） |

类别在表格中以原始小写形式显示（例如`network`、`automation`）。

### 审批提示

当 AI 调用某个技能时，aiFetchly 可能会在其运行前请求您审批。是否出现提示取决于技能的类别**以及**您当前的聊天工具审批模式：

| 类别 | 审批行为 |
|--------|-------------------|
| `pure` | 始终自动批准——无提示。 |
| `shell` | **每条命令都会提示。**永不自动批准（见下文）。 |
| `network` / `filesystem` / `automation` | 在默认的_"请求审批"_模式下会提示。在_"代我批准"_或_"完全访问"_模式下会自动批准。 |

当出现提示时，您会看到一张审批卡片，包含三个操作：

- **允许一次**——仅运行本次调用。
- **始终允许**——记住此决定，今后调用该技能时不再提示。
- **拒绝**——阻止本次调用。

对于**shell**技能，卡片标题为**"Shell 命令执行"**，会显示命令预览（命令、工作目录、shell、超时时间），且第三个按钮显示为**"始终允许（本次会话）"**，而非"始终允许"。

:::warning Shell 审批实际上是一次性的

对于`shell`技能，"始终允许"对后续命令**不**生效。每条 shell 命令都会再次提示——这是有意为之的安全措施，因为 shell 命令可以在您的机器上执行任何操作。只有非 shell 类别才会真正永久记住"始终允许"。

:::

## 技能包格式

技能`.zip`必须包含一个`manifest.json`。最小可用的清单如下所示：

```json
{
  "name": "my-custom-skill",
  "version": "1.0.0",
  "description": "What this skill does, shown to the AI.",
  "runtime": "javascript",
  "entry": "index.js",
  "parameters": {
    "type": "object",
    "properties": {
      "url": { "type": "string" }
    },
    "required": ["url"]
  },
  "permissions": ["network"]
}
```

### 必需的清单字段

| 字段 | 说明 |
|-------|-------------|
| `name` | 唯一的技能标识符。 |
| `version` | 版本字符串，例如`1.0.0`。 |
| `description` | 简短描述——AI 会读取此内容来判断何时使用该技能。 |
| `runtime` | `javascript`或`python`。 |
| `entry` | 包内的入口文件（例如`index.js`或`main.py`）。 |
| `parameters` | 描述技能输入参数的 JSON Schema 对象。 |

### 可选的清单字段

| 字段 | 说明 |
|-------|-------------|
| `permissions` | 权限字符串数组。**有效值仅为`network`、`filesystem`、`automation`。**第一项决定技能的类别（参见[技能类别](#技能类别)）。未知值在导入时会被拒绝。 |

:::danger 权限会被严格校验

仅接受`network`、`filesystem`和`automation`。诸如`web-search`、`data-access`或`shell`之类的值将被拒绝，技能也不会被导入。没有单独的`category`字段——类别由`permissions`的第一项派生（如未提供则为`pure`）。

:::

### 打包

1. 在包的根目录放置一个有效的`manifest.json`。
2. 添加`entry`引用的运行时/入口文件。
3. 压缩**内容**，而非外层文件夹。
4. 将文件命名为`skill-name.zip`。

## 故障排除

### 导入失败

**可能的原因：**zip 无效、`manifest.json`缺失或格式错误、`permissions`值无效，或缺少必需字段（`runtime`、`entry`、`parameters`）。

**解决方案：**
1. 验证 zip 文件的完整性。
2. 检查`manifest.json`是否包含所有必需字段且值有效。
3. 确认`permissions`仅使用`network`、`filesystem`或`automation`。
4. 确认`runtime`为`javascript`或`python`，且`entry`指向真实存在的文件。

### 技能未在聊天中出现

**可能的原因：**技能已被禁用，或（对于插件技能）其所属插件已被禁用。

**解决方案：**
1. 在表格中检查该技能的状态并启用它。
2. 对于插件技能，请查看**[插件管理器](./plugin-manager)**——其所属插件必须处于启用状态。

### AI 不断请求审批

- 您正在使用**shell**技能。Shell 审批在设计上就是一次性的。
- 对于其他类别，可将聊天工具审批模式切换为_"代我批准"_以减少提示（注意：这会自动批准非 shell 技能）。

### 内置技能没有切换按钮

这是有意为之。内置技能始终处于启用状态，无法在此页面被禁用或卸载。
