# ワークスペース記憶

ワークスペース記憶は、承認済みワークスペースに対して AI Chat がプロジェクト固有の文脈を保持する機能です。グローバルなユーザー記憶や会話記憶とは別なので、あるプロジェクトの詳細が別のプロジェクトで再利用されません。

同じプロジェクトフォルダー、キャンペーンワークスペース、リポジトリで繰り返し使う永続的な情報に使います。

## 覚える内容

| 種類 | 用途 |
|---|---|
| **Project** | ファイルから明らかではない製品、キャンペーン、マイルストーン、プロジェクト文脈。 |
| **Decision** | ユーザーが承認した製品または技術上の決定。 |
| **Workflow** | このワークスペースのコマンド、レビュー手順、運用手順。 |
| **Convention** | コーディング、文章、命名、UX の規約。 |
| **Reference** | ローカルファイル、ドキュメント、仕様、外部リソースへの参照。 |
| **Warning** | 既知の落とし穴、制限された操作、不安定なテスト、コンプライアンス規則、セキュリティ制約。 |

秘密情報、API キー、Cookie、非公開のリードデータ、完全な会話ログ、大きなツール出力、生ファイル内容、一時的な作業進捗は保存しないでください。

## スコープ

ワークスペース記憶は、現在の AI Chat 会話に承認済みワークスペースがある場合だけ使えます。

aiFetchly はワークスペースを安定した ID に解決します。選択フォルダーが Git リポジトリ内にある場合、記憶はリポジトリルートに紐づきます。Git ルートがない場合は、選択された実パスに紐づきます。

つまり:

- 同じ承認済みワークスペースの会話は記憶を共有できます。
- あるワークスペースの記憶は別のワークスペースに注入されません。
- 承認済みワークスペースがない場合、ワークスペース記憶は開いたり使用したりできません。

## 開く方法

1. **AI Chat** を開きます。
2. コンポーザー上部のワークスペース領域でワークスペースを選択または承認します。
3. ワークスペースバッジの **記憶** をクリックします。

ダイアログには現在のワークスペースの有効な記憶が表示されます。バッジには有効な記憶数も表示されます。

## 記憶を作成する

1. ワークスペース記憶ダイアログを開きます。
2. **Create memory** をクリックします。
3. **Type** を選びます。
4. 短い **Title** を入力します。
5. **Content** を入力します。
6. **Confidence** を設定します。
7. **Save** をクリックします。

手動記憶は、現在の承認済みワークスペースだけに保存されます。

## フィールド

| フィールド | 説明 |
|---|---|
| **Type** | project、decision、workflow、convention、reference、warning の分類。 |
| **Title** | 一覧と検索のための短いラベル。 |
| **Content** | 記憶本文。簡潔で長く使える内容にします。 |
| **Confidence** | 0 から 100 の信頼度。手動記憶は高めから始まりますが、必要に応じて下げられます。 |
| **Status** | 編集時に使用可能: active、archived、contradicted。 |

## 検索と確認

検索ボックスでタイトルまたは内容から記憶を探せます。

各行には種類、タイトル、内容、非 active の場合のステータス、ソース、更新日時、最終使用日時、信頼度が表示されます。**Show archived** をオンにすると archived と contradicted の記憶も表示されます。

## 編集、アーカイブ、削除

- **Edit** は種類、タイトル、内容、信頼度、ステータスを更新します。
- **Archive** は削除せずに有効リストから隠します。
- **Delete** は確認後に完全に削除します。

アーカイブ済み記憶は **Show archived** が有効な場合だけ表示されます。

## ワークスペース自動要約

ワークスペース自動要約は、内部では workspace auto-dream と呼ばれ、会話やエージェントタスクからプロジェクト固有の情報を統合できます。

ダイアログでは:

- バッジが有効な記憶数と自動要約ステータスを表示します。
- **RUN AUTO SUMMARY** で現在のワークスペースの手動統合を開始します。
- 利用可能な場合は最終実行時刻が表示されます。

生成された記憶も確認、編集、アーカイブ、削除できます。

## 設定

| 設定 | 効果 |
|---|---|
| **ワークスペース記憶の注入** | 承認済みの現在のワークスペースに関連する記憶を AI Chat コンテキストへ注入します。 |
| **ワークスペース自動要約** | 会話やエージェントタスクからワークスペース固有の記憶をバックグラウンドで統合します。 |
| **手動ワークスペース記憶** | 手動で作成、編集、削除できるようにします。無効化しても保存済み記憶は削除されません。 |

現在のユーザーメッセージが優先されます。記憶と現在の指示が矛盾する場合、現在の指示が優先されるべきです。

## ベストプラクティス

- 毎回説明するのが面倒な決定や規約を保存します。
- スクリプトや docs から明らかでないプロジェクトコマンドを保存します。
- コンプライアンス、安全、環境、既知のテスト問題を警告として保存します。
- 記憶は短く保ちます。
- 大きなファイル内容をコピーするより、パスや docs を参照します。
- 古い記憶は、矛盾した active ガイダンスとして残さずアーカイブします。
